# Authentication System - Quick Start

## Installation (5 minutes)

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Authentication
```bash
npm run setup:auth
```
This automatically:
- Generates secure JWT secrets
- Updates your .env file
- Shows next steps

### 3. Run Database Migration
```bash
# PostgreSQL
psql -U your_user -d your_db -f src/database/migrations/003_auth_system.sql

# Or using npm migrate script (if configured)
npm run migrate
```

### 4. Start Server
```bash
npm run dev
```

Server runs at: http://localhost:3000

## Quick Test

### 1. Register User
```bash
curl -X POST http://localhost:3000/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "Test123456",
    "fullName": "Test User"
  }'
```

Response:
```json
{
  "success": true,
  "user": { "id": 1, "email": "test@example.com", ... },
  "accessToken": "eyJhbGc...",
  "refreshToken": "eyJhbGc..."

```

### 2. Login
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{

  }'
```

### 3. Get User Info
```bash
curl http://localhost:3000/api/auth/me \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## API Endpoints

| Method | Endpoint | Auth Required | Description |
|--------|----------|---------------|-------------|
| POST | `/api/auth/signup` | No | Register new user |
| POST | `/api/auth/login` | No | Authenticate user |
| POST | `/api/auth/refresh` | No | Refresh access token |
| POST | `/api/auth/logout` | Yes | Logout (revoke refresh token) |
| POST | `/api/auth/logout-all` | Yes | Logout all devices |
| GET | `/api/auth/me` | Yes | Get current user info |

## Protecting Your Routes

### Option 1: Require Authentication
```javascript
const { authenticate } = require('./middleware/auth');

router.get('/api/products', authenticate, (req, res) => {
  // req.user contains { id, email, role, fullName }
  res.json({ userId: req.user.id });
});
```

### Option 2: Require Specific Role
```javascript
const { authenticate, authorize } = require('./middleware/auth');

router.delete('/api/admin/users/:id', 
  authenticate, 
  authorize('admin'), 
  (req, res) => {
    // Only admins can access
  }
);
```

### Option 3: Optional Authentication
```javascript
const { optionalAuth } = require('./middleware/auth');

router.get('/api/products', optionalAuth, (req, res) => {
  if (req.user) {
    // Personalized response for logged-in users
  } else {
    // Public response
  }
});
```

## Frontend Integration

### 1. Install in Next.js App
Copy these files to your Next.js project:
- `context/AuthContext.js` (see docs/AUTHENTICATION.md)
- `lib/axios.js` (axios interceptor)
- `components/ProtectedRoute.js`

### 2. Wrap App with Auth Provider
```javascript
// pages/_app.js
import { AuthProvider } from '../context/AuthContext';

export default function App({ Component, pageProps }) {
  return (
    <AuthProvider>
      <Component {...pageProps} />
    </AuthProvider>
  );
}
```

### 3. Use in Components
```javascript
import { useAuth } from '../context/AuthContext';

export default function MyComponent() {
  const { user, login, logout } = useAuth();

  if (!user) {
    return <button onClick={() => login('email', 'pass')}>Login</button>;
  }

  return (
    <div>
      <p>Welcome {user.fullName}</p>
      <button onClick={logout}>Logout</button>
    </div>
  );
}
```

### 4. Protect Pages
```javascript
import ProtectedRoute from '../components/ProtectedRoute';

export default function Dashboard() {
  return (
    <ProtectedRoute>
      <h1>Dashboard</h1>
    </ProtectedRoute>
  );
}
```

## Configuration

### Environment Variables (.env)
```env
# Generated by setup:auth script
JWT_SECRET=your-64-char-secret
JWT_REFRESH_SECRET=your-64-char-refresh-secret

# Database (existing)
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database
DB_USER=your_user
DB_PASSWORD=your_password
```

### Customization

**Change token expiry:**
```javascript
// src/services/auth-service.js
const ACCESS_TOKEN_EXPIRY = '15m';  // Change to '30m', '1h', etc.
const REFRESH_TOKEN_EXPIRY = '7d';  // Change to '14d', '30d', etc.
```

**Change rate limit:**
```javascript
// src/routes/auth.js
if (validRequests.length >= 5) {  // Change to 10, 15, etc.
```

**Change password requirements:**
```javascript
// src/routes/auth.js
const validatePassword = (password) => {
  return password && password.length >= 8;  // Adjust as needed
};
```

## Common Issues

### "Invalid or expired token"
- Access token expired (15 min default)
- Solution: Use axios interceptor for auto-refresh

### "Too many requests"
- Hit rate limit (5 attempts / 15 min)
- Solution: Wait 15 minutes or clear login_attempts table

### "Email already registered"
- User tried to signup with existing email
- Solution: Use login instead or implement "forgot password"

### CORS errors
- Frontend domain not whitelisted
- Solution: Update CORS config in server.js
